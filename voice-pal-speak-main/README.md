# SpeakMate 🎤

An AI-powered English speaking practice app that helps users improve fluency, confidence, and vocabulary through real-time voice interactions.

---

## 🚀 Features
- 🎙️ Real-time voice conversations
- 🤖 AI-powered feedback
- 📊 Track speaking performance
- 💡 Clean and simple UI

---

## 🛠️ Tech Stack
- React (Vite)
- TypeScript
- Tailwind CSS

---

## 📦 Run Locally

```bash
npm install
npm run dev
